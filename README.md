# Predecessor CZ/SK – průvodce hrou (hotový web)

Tohle je **zbuildovaná** verze webu – nahraj obsah této složky do GitHub repozitáře a zapni GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `(root)`).

Zdrojové soubory pro úpravy jsou ve složce `predecessor-czsk-guide-v2` (texty v `src/data/`).
Po úpravě: `npm install` → `npm run build` → obsah složky `dist/` nahraj sem místo starých souborů.
